# Create a Review Legal Contracts skill
Create a skill to review Legal Contracts. It should default to the Legal Contracts unless the user specifies another document library. Check each contractor for a Lawyer ID. The Lawyer ID is in the xxx-xxx format (where x is an alphanumeric character: a-z, A-Z, 0-9). Log any legal contacts that do not have a Lawyer ID to the Invalid Contracts list. Create the list if it doesn't exist.
